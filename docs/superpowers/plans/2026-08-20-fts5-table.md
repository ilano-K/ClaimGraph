# FTS5 Table Creation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the `documents_fts` SQLite FTS5 virtual table at backend startup via raw DDL.

**Architecture:** A tiny module `app/db/fts.py` exposes an `ensure_fts5_table(engine)` helper that runs idempotent `CREATE VIRTUAL TABLE IF NOT EXISTS` DDL. The FastAPI lifespan calls it in `main.py` right after `Base.metadata.create_all(bind=engine)`. No ORM model, no CRUD, no search routes.

**Tech Stack:** SQLAlchemy 2.0.51 (already in environment), SQLite (built-in FTS5), FastAPI, pytest.

## Global Constraints

- SQLAlchemy 2.0.x is used with `Mapped` / `mapped_column` 2.0-style ORM (see `app/db/models.py`).
- The database is SQLite at `%LOCALAPPDATA%/claim-graph/app.db` (`DATABASE_PATH` in `app/core/config.py`).
- Table name must be exactly `documents_fts`.
- Columns must be exactly `workspace_id UNINDEXED`, `document_id UNINDEXED`, `content` (indexed).
- Tests are gitignored by repo convention (`backend/tests/` is in `.gitignore`); commit only tracked source files, never force-add tests.
- Current working directory for all commands is `backend/`.
- No code comments unless the existing surrounding code uses them; module docstrings follow existing style.

```python
"""FTS5 virtual table creation for full-text search over document content."""
from sqlalchemy.engine import Engine

# workspace_id and document_id are UNINDEXED keys for scoping/filtering;
# content is the searchable, tokenized column.
FTS5_DDL = """
CREATE VIRTUAL TABLE IF NOT EXISTS documents_fts
USING fts5(workspace_id UNINDEXED, document_id UNINDEXED, content)
"""


def ensure_fts5_table(engine: Engine) -> None:
    """Create the documents_fts FTS5 virtual table if it does not exist."""
    with engine.connect() as conn:
        conn.exec_driver_sql(FTS5_DDL)
```
